# Coffee Rating App

A full-stack coffee rating application built with React, Node.js, Express and MongoDB.

## Features

- View coffee records
- Search coffees
- Filter by origin
- Filter by roast
- View coffee ratings
- Vote for coffees
- Store coffee data in MongoDB

## Tech Stack

### Frontend
- React
- Vite
- CSS

### Backend
- Node.js
- Express
- MongoDB
- Mongoose
